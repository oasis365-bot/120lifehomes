# 케어홈즈 (CareHomes) — 요양시설 검색 플랫폼 데모

일본 최대 요양시설 검색 사이트 **LIFULL 介護 (kaigo.homes.co.jp)** 의 정보 구조·화면 구성을
분석해, **한국 노인장기요양보험 제도에 맞게 재해석**한 정적 웹사이트 데모입니다.

> ⚠️ 모든 시설명·주소·연락처·요금·후기는 가상의 예시이며 실제 기관과 무관합니다.
> 상담 폼은 전송되지 않습니다.

## 페이지 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 메인 — 조건 검색 박스, 지역/유형 그리드, 특집, 신규 시설, FAQ |
| `search.html` | 시설 검색 — 좌측 필터(지역·유형·등급·요금·편의), 정렬, 결과 카드 |
| `facility.html` | 시설 상세 — `?id=f01` 파라미터, 소개·기본정보·비용·후기·유사 시설 |
| `guide.html` | 돌봄 가이드 — 장기요양등급 신청 절차, 비용 개념, FAQ |
| `consult.html` | 무료 입소 상담 신청 폼 (데모, 미전송) |

## 기술

- 순수 HTML/CSS/JS (빌드 불필요, 의존성 없음)
- `assets/js/data.js` — 지역·유형·등급·시설 데이터 및 공통 유틸
- `assets/js/app.js` — 공통 헤더/푸터 주입, 시설 카드 렌더, 글자 크기 조절
- 폰트: Google Fonts (Noto Sans KR)
- 반응형 (모바일 햄버거 메뉴 포함)

## 실행 방법

정적 파일이므로 `index.html` 을 브라우저로 열면 됩니다.
`fetch` 를 쓰지 않으므로 `file://` 로도 동작하지만, 로컬 서버 사용을 권장합니다.

```bash
npx serve .
```

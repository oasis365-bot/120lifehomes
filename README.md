# 120 라이프홈즈 (120lifehomes) — 요양시설 검색 플랫폼

일본 최대 요양시설 검색 사이트 **LIFULL 介護 (kaigo.homes.co.jp)** 의 정보 구조·화면 구성을
분석해, **한국 노인장기요양보험 제도에 맞게 재해석**한 요양시설 검색 사이트.
도메인: `120lifehomes.com`

> ⚠️ 현재는 초기 버전으로, 게시된 시설명·주소·연락처·요금·후기는 가상의 예시입니다.
> 실제 시설 데이터는 이후 공공데이터포털(장기요양기관 검색 서비스) 연동으로 대체 예정.
> 상담 폼도 백엔드(Supabase) 연결 전까지는 전송되지 않습니다. 배포 절차는 `DEPLOY.md` 참고.

## 기술

- 순수 HTML/CSS/JS (빌드 불필요, 의존성 없음)
- `assets/js/data.js` — 지역·유형·등급·시설 데이터 및 공통 유틸
- `assets/js/app.js` — 공통 헤더/푸터 주입, 시설 카드 렌더, 글자 크기 조절
- 폰트: Google Fonts (Noto Sans KR)
- 반응형 (모바일 햄버거 메뉴 포함)

## 로고 교체 방법

로고는 `assets/logo.svg` 파일입니다. 헤더에서 `assets/js/app.js` 의 `mountChrome()` 안
`<img src="assets/logo.svg" ...>` 로 불러오고, 오른쪽 `<span class="logo-tag">` 이 "전국 요양시설
정보 리뷰 포털" 부가문구입니다.

- **로고 이미지만 교체**: `assets/logo.svg` 를 새 파일로 덮어쓰기 (SVG 권장, PNG면 배경 투명)
- **크기 조정**: `assets/css/style.css` 의 `.logo .logo-img { height: 46px }`
- **부가문구 수정/삭제**: `app.js` 의 `<span class="logo-tag">...</span>`

## 실행 방법

정적 파일이므로 `index.html` 을 브라우저로 열면 됩니다.
`fetch` 를 쓰지 않으므로 `file://` 로도 동작하지만, 로컬 서버 사용을 권장합니다.

```bash
npx serve .
```
